This repository contains a Big Data Analytics project completed during my MSc in Big Data and Data Science. The work focuses on analysing large-scale datasets to identify trends, patterns, and relationships that can support informed decision-making.

The project covers key stages such as data preparation, transformation, and exploratory analysis, followed by the application of analytical techniques to interpret results effectively. It demonstrates the practical use of data analytics in handling high-volume data and generating meaningful insights.

Developed in Python within a Jupyter Notebook environment, the project makes use of libraries including Pandas, NumPy, and Matplotlib. It reflects my ability to work with complex datasets, apply analytical methods, and present findings in a clear and structured manner
